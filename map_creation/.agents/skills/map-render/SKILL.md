# Drive a rendering cycle

Read [the tool reference](../../../docs/tools.md) and [walkthrough](../../../docs/walkthrough.md). The bundled helper handles small maps, not large production atlases; read [scaling](../../../docs/scaling.md) if the intended canvas exceeds its limit.

## Prepare

Work from complete regional intent, including all intersecting sites and full feature connections. Choose a native rectangle after geography. Run `prepare` with a fresh candidate ID. Inspect the guide and accepted context and supplement the saved brief with widths, flow directions, entrances and boundary obligations that geometry alone cannot convey. Keep the actual submitted prompt as provenance.

For an existing good painting, use `--mask` with a canvas-aligned local grayscale mask; black protects existing pixels. Refinement uses the current native painting as the edit target. Do not regenerate correct geography merely to improve a house.

## Paint and retain

Use the user's configured image tool according to its instructions, or hand the prepared inputs to a manual editor. State image roles: target, structural guide, style reference and accepted surrounding context. Do not imply the script itself generates painted artwork.

Retain the returned original, check actual dimensions and ingest with a completed provenance record. The helper rejects wrong dimensions instead of silently upscaling. If sizes differ, retain the output outside the candidate and prepare a compatible new rectangle or revised approach. Do not claim additional native detail from enlargement.

## Inspect and accept

Run `inspect`, then apply [visual review](../../../docs/review.md) to the overview, all native crops, mask perimeter and every affected neighbouring side. Follow complete rivers and journeys beyond the candidate. Confirm all required sites are accounted for; labels or planned anchors do not prove they were painted.

Complete every required review check with an observation and evidence. Use fail or unclear honestly. Record reviewer identity and actual user approval separately. `accept` checks source freshness, image hashes and complete review records; it cannot judge the pixels for you.

Prepare subsequent work from the accepted revision. If inputs change, use a new ID rather than editing a sealed candidate. For repair, prepare a new masked candidate covering a coherent feature and its surroundings, then repeat the same review cycle.

## Persist

Keep lossless returned masters, integrated candidates, masks, provenance, reviews and accepted state. Record rejected attempts and reasons. Show safe overview JPEGs and native local crops, not full atlas masters. Report measured call counts and unresolved artistic limits, not one-shot reliability.
