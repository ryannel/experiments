# Credits and provenance

This kit is adapted from the owner's Lantern Sea world-building experiment, developed through iterative work with Codex and AI image generation.

- **Adapted methods:** the Lantern forest and village skills, atlas production playbook, catchment review, political-space review, atmosphere review and resolution/retention lessons.
- **New for this package:** director, art-direction, world-planning, rendering and release skills; public templates and documentation; Bracken Reach fictional example; small-map Python helper, tests and allowlist packager.
- **Selected source artwork:** the label-free atlas overview, with its exact source hash and review limits in [showcase/provenance.json](showcase/provenance.json).
- **Runtime dependency:** [Pillow](https://python-pillow.org/), installed separately under its own license. No dependency implementation is vendored here.
- **Agent integration reference:** [official skill documentation](https://learn.chatgpt.com/docs/build-skills), consulted 16 September 2026. The kit is an independent experiment, not an official OpenAI map product.

No original private setting documents, full atlas masters, third-party inspiration images, credentials or global machine configuration are bundled. The public adaptations do not require the original repository. Each newly supplied reference or artwork asset needs its own provenance and reuse terms.
