# Start a map

Choose a scope first: a world atlas, a region for journeys, or a settlement for local play. Each has a different visual unit. An atlas town marker can represent thousands of people; a house in a village drawing might represent one household. Neither automatically sets ground scale.

A useful first conversation covers:

1. **Purpose:** who will use the map, at what screen/print size, and what must they understand?
2. **Premise:** tone, geography, technology, level of magic and a few defining places.
3. **World size:** approximate distances, travel experience, population scale and political complexity—or explicitly leave them illustrative.
4. **Art:** what should the map feel like, what references are available to use, and how close will viewers zoom?
5. **Production:** tools, time/generation budget, what already exists, and where the user wants creative checkpoints.

Ask these in a short conversation rather than issuing a large questionnaire. Offer two or three concrete directions when preferences are unclear. Treat defaults as proposals and document them. The [brief template](../templates/brief.md) is a record, not a test the user must fill in unaided.

## Bring your own material

An existing setting establishes names and relationships, not necessarily final geometry. Import a public-safe subset into the world and society records. Keep private plot explanations outside those files. An existing painting establishes observed coastlines and architecture; use it as the base for a bounded edit rather than rebuilding correct terrain from an approximate guide.

For an image-only map, first record native dimensions and mark known rivers, routes and landmarks in world pixels. Label uncertain observations as uncertain. The helper can use a retained base image through `new --base`; it does not automatically recognize terrain or infer a world model. Reconcile the model manually before expansion. Never claim a traced image is surveyed geography.

For new maps, the included example is a starting structure. Rename, reshape or replace it; no original Lantern Sea lore is required.

## Start small enough to learn

Trial a representative region that contains a river crossing, woodland edge, settlement and exposed terrain. Choose the hardest style or geometry relationship, not just the prettiest empty corner. If that crop fails, improve the recipe before creating a world-sized asset library or commissioning dozens of tiles.
