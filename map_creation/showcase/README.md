# Showcase provenance

`atlas-preview.jpg` is an unchanged copy of the label-free, 1600 × 1067 JPEG overview from the original Lantern Sea map-making project. It is included as a selected public demonstration of the visual workflow. It contains no labels or embedded GM explanation.

The source release record describes a native 12,276 × 8,184 atlas assembled from 81 painted production tiles, with lossless masters and local repair records retained in the original project. The final record states agent visual review completed and user review of the finished eastern expansion pending. This package does not upgrade that status to user approval.

The painting was created through AI image generation with authored guides, repeated review and local corrections. This preview cannot be used to reconstruct the full atlas, and the new offline helper does not produce this image. No raw private prompts, setting documents or full-resolution source masters are included.

`provenance.json` records the preview's hash, dimensions, source release identifier and review status without machine-specific paths. See [reuse terms](../LICENSE.md). The separate Bracken Reach image is a schematic example generated by the bundled Python script.
