# Working on the olfactory taxonomy

Read README.md and PROVENANCE.md first. This is an independent experiment.

- Treat data/taxonomy.json as the authoritative transcription of the user's table. Preserve terminology; do not silently correct or reclassify notes.
- Scope family identity by realm: TOBACCO occurs in two different realms.
- Keep photographic artwork separate from exact chart geometry and editable labels.
- The Citrus proof is a style study, not an assembly-ready tile or a dimensionally correct sector.
- Use the built-in image generation tool for new photographic assets; retain prompts and record provenance. Do not silently switch to an API workflow.
- Keep paths relative, require no sibling projects, and keep large production exports under ignored build/.
- Run python3 scripts/build_layout.py and verify the result before submitting changes.
- Physical size, output medium, ring radii, typography, tile size and overlap remain undecided. Do not claim production readiness.
