# Provenance and reuse

## Taxonomy
data/taxonomy.json transcribes the 48-row classification table supplied by the repository owner in the project conversation on 2026-10-03. Repeated spaces and layout whitespace were normalized; wording, row order and weights were retained. This is a working descriptive taxonomy, not an independently validated scientific standard.

## Original reference
references/olfactive-taxonomy-original.jpg is the owner's supplied OlfactiveTaxonomy@0.5x.jpg, copied without modification. It is an unfinished visual reference. The table takes precedence where labels differ (for example the Aldehydic note). The origins and licensing of photographs embedded in that collage have not been documented.

## Generated proof
examples/citrus-visual-proof.png was generated on 2026-10-03 using the built-in image_gen tool, with the original chart as a style reference. The exact prompt is in prompts/citrus-visual-proof.txt. It is a generated demonstration, not a production sector. Geometry is illustrative; some typography differs from the requested verbatim labels.
